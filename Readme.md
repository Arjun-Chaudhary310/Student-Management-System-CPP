# Student Management System (C++)

## 📌 Overview
The **Student Management System** is a console-based C++ application designed to manage student records efficiently. The project demonstrates core Computer Science concepts such as **Object-Oriented Programming (OOP)** and **file handling**, and implements full **CRUD (Create, Read, Update, Delete)** operations.

This project is suitable for beginners and is ideal for showcasing foundational C++ and system design skills on resumes and LinkedIn.

---

## 🎯 Features
- Add new student records
- Display all students
- Search student by roll number
- Update existing student details
- Delete student records
- Persistent data storage using binary files

---

## 🛠 Tech Stack
- **Language:** C++
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - File Handling (Binary Files)
  - Menu-driven programs
- **Tools:** VS Code / Dev C++

## ⚙️ How to Run the Project

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/Student-Management-System-Cpp.git
```

### 2️⃣ Navigate to Project Folder
```bash
cd Student-Management-System-Cpp
```

### 3️⃣ Compile the Program
```bash
g++ main.cpp -o student
```

### 4️⃣ Run the Program
```bash
./student
```
